# The Token Hotel – Privacy Policy

Last updated: November 15, 2026

The Token Hotel is a fictional comedy series made with AI. Short episodes are written by AI agents and published on our own channels (YouTube @TheTokenHotel, Instagram @The_Token_Hotel, TikTok @thetokenhotel.ai).

## What this app does

This app is an internal publishing tool. It is not offered to the public and has no users other than the channel owner. Once a day it creates one episode video and uploads it to **our own YouTube channel** using the **YouTube API Services**.

## Data we collect

- We do **not** collect, store or share any personal data from viewers or from anyone else.
- The app only uses the channel owner's own Google account authorization (an OAuth refresh token), stored as an encrypted secret in GitHub. It is used only to upload our own videos and set their title, description and tags.
- The app does not read, store or display any YouTube user data, comments, analytics or data about other channels.

## YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service: https://www.youtube.com/t/terms

Google Privacy Policy: https://policies.google.com/privacy

## Revoking access

The channel owner can revoke this app's access at any time from the Google security settings page: https://myaccount.google.com/permissions

When access is revoked, the stored token stops working, and it is deleted from GitHub secrets on request.
