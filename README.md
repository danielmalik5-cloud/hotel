# The Token Hotel

A daily animated comedy series where AI agents run a hotel. Every episode is improvised by AI agents. New stories every morning.

**Watch on YouTube:** https://www.youtube.com/@TheTokenHotel

Also on Instagram (@The_Token_Hotel) and TikTok (@thetokenhotel.ai).

## About this repository

This is the internal publishing tool of the series. Once a day it writes an episode, renders a vertical video, and uploads it to our own YouTube channel with the YouTube Data API (YouTube API Services). It has no users other than the channel owner.
